# Homelab Overview

## Hardware

- Raspberry Pi 5
- External SSD for persistent storage

## Platform

- Raspberry Pi OS
- Docker
- Docker Compose

## Services

### Pi-hole
Provides network-wide DNS filtering.

### Jellyfin
Hosts and streams media stored on the external SSD.

### Portainer
Provides a web interface for managing Docker containers.

### PhotoPrism
Provides self-hosted photo organization and management.

## Goals

This homelab is used to gain hands-on experience with:

- Linux administration
- Docker and containerization
- Networking
- DNS
- Self-hosted services
- System troubleshooting
