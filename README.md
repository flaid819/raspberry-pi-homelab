# Raspberry Pi Homelab

A Raspberry Pi 5 homelab used to host self-managed services with Docker and experiment with Linux, networking, containerization, and system administration.

## Current Services

- **Pi-hole** — Network-wide DNS filtering
- **Jellyfin** — Self-hosted media server
- **Portainer** — Docker container management
- **PhotoPrism** — Self-hosted photo management

## Repository Structure

- `configs/` — Docker Compose configurations for hosted services
- `docs/` — Homelab documentation and diagrams
- `scripts/` — Automation and administration scripts
